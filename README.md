# Chemophile Part 1 (for 11th Class)

Website for **Chemophile**, a Hinglish visual booklet series for NCERT Class 11 Chemistry by **Mohd Adeel Khan (Adeel Sir)**, MSc BEd (JMI).

The site (`index.html`) shows:

- all 8 chapters (Chapter 2 to Chapter 9) with every topic, sub-topic, NCERT section number and page number, taken from each booklet's "Is chapter mein kya hai" page
- a search box to find any topic across all chapters
- 5 sample pages per chapter (cover, contents and the first pages of Topic 1); the full booklets are not published here
- a "Padh liya" study tracker saved in the visitor's own browser
- contact details to get the booklets

## Files

- `index.html`: the whole site (HTML, CSS, chapter data and JS in one file)
- `assets/pages/`: sample pages at 1000 px wide (WebP)
- `assets/thumbs/`: the same pages at 360 px wide for covers and thumbnails

To add or change a chapter, edit the `CHAPTERS` list near the bottom of `index.html` and put its sample pages in `assets/pages/` and `assets/thumbs/` as `ch<N>-<page>.webp`.

## View it

Open `index.html` in a browser, or publish with GitHub Pages: **Settings → Pages → Deploy from a branch**, then choose the branch and `/ (root)`.
