Books & prices
What the website sells: classes, books, chapters, prices, MRPs, combos and the offer banner.

        See the website ↗

      
The website still uses the built-in list. Check the prices below and tap Save changes once; after that, the website follows this page.

      
Ways to buy
Tick the formats the website should offer. The name and note show on the order form.

      
Offer banner
A strip on top of the website, e.g. "Diwali offer: 20% off all combos till 5 Nov".

      
Classes, books and chapters
Price is what the student pays. MRP is optional: if it is higher, the website shows it crossed out with the % off. Leave a price empty if that format isn't sold for the chapter. "Coming soon" chapters show on the website but can't be ordered.

        

      

      
Combos
A set of chapters at one special price, e.g. "Class 11 full book".

      

      
Unsaved changes · the website changes only after you save.

    


    

      
Chapters
Upload each chapter's PDF once. Students read it as a book.

      

        
Each PDF page is turned into an image for the online reader. The PDF itself is not stored anywhere, and students get no download option. Upload in Chrome on a laptop or phone, and keep this page open until the upload finishes. Uploading again replaces the old pages.
